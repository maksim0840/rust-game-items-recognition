# Rust-Game-Items-Recognition

Распознавание предметов игры Rust по иконкам: обученная нейросеть и
десктоп-приложение на её основе.

**Скачать программу: [LootLens](https://github.com/maksim0840/rust-items-detection/releases/tag/v1.0)**

## [app/](app#readme) — программа LootLens

Отмечаете предметы, которые ищете, и нажимаете горячую клавишу: программа
снимает экран, распознаёт содержимое сундука и подсвечивает найденные ячейки
прямо поверх игры.

## [research/](research#readme) — обучение модели

Как получена нейросеть: подготовка данных, вычисление сетки ячеек, выбор
архитектуры, метод обучения и метрики. Итог — **99.83% top-1 accuracy** на 1211
классах предметов.
