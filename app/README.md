# LootLens

Помощник для игры Rust: пользователь отмечает предметы, которые ищет, а
программа по горячей клавише снимает экран, распознаёт содержимое сундука
нейросетью и подсвечивает найденные ячейки прямо поверх игры.

## Запуск из сходников

```bash
pip install -r app/requirements.txt
python app/app.py
```

Проверено на Python 3.11, Windows 11.

### Ключи запуска

| Ключ | Что делает |
|---|---|
| `--allow-capture` | Разрешает скриншотам и записи экрана видеть квадраты поверх игры. По умолчанию они невидимы |

```bash
python app/app.py --allow-capture
```

## Сборка в .exe

```bash
pip install pyinstaller
cd app
pyinstaller --noconfirm --clean --distpath . --workpath build LootLens.spec
```

Сборкой управляет `LootLens.spec` — это обычный Python-файл, который
PyInstaller выполняет, чтобы узнать, что и как упаковывать.

## Как пользоваться

1. **Окно настроек.** Указать масштаб интерфейса и монитор так же, как
   выставлено в самой игре. Разрешение подставится по выбранному монитору.
2. **Выбор предметов.** Отметить нужные предметы кликом по карточке. Есть
   вкладки категорий, поиск по названию и выделение всего показанного.
3. **Кнопка «Выбрать (N)».** Открывает панель распознавания и одновременно
   поднимает прозрачное окно поверх игры.
4. **Панель распознавания.** Назначить горячие клавиши: одну для запуска,
   другую для очистки результата. Флажки управляют тем, какие группы
   показывать.
5. **Нажать горячую клавишу.** Работает даже когда программа свёрнута, а игра
   развёрнута на весь экран. На экране появятся счётчики и подсвеченные ячейки.

Результат делится на три группы: найденные предметы, нераспознанные ячейки и
предметы, которые распознались, но не запрашивались.

```

ui/                   всё, что видит пользователь

  styles.py           тёмная тема (одна таблица стилей на всё приложение)
  settings_window.py  стартовое окно настроек игры
  items_browser.py    сетка предметов с категориями и поиском
  scan_panel.py       управление распознаванием: флажки, бинды, счётчики
  overlay.py          полупрозрачный слой внутри окна программы
  game_overlay.py     прозрачное окно поверх игры с подсветкой ячеек
  spinner.py          индикатор загрузки

system/               работа с Windows через ctypes
  monitors.py         список мониторов, названия моделей из EDID
  screen_capture.py   снимок экрана в настоящих пикселях
  global_hotkeys.py   горячие клавиши на уровне системы

  pipeline.py         модель, сетка ячеек инвентаря, сканер экрана

model/                веса модели и параметры обработки

source/ui/            ресурсы интерфейса
```

## Как работает распознавание

`detection/pipeline.py` содержит три части:

- **`InventoryGrid`** — считает координаты ячеек сундука аналитически, по
  разрешению экрана и масштабу интерфейса из настроек. Никакого поиска на
  картинке: сетка 6×8 предсказывается формулой, поэтому шаг почти бесплатный.
- **`ItemRecognitionModel`** — модель ONNX (107 МБ) превращает картинку ячейки
  в вектор из 256 чисел и сравнивает его с центроидами 1211 классов. Если
  близость ниже порога 0.73, ячейка считается нераспознанной.
- **`InventoryScanner`** — связывает всё: снимает экран, режет на 48 ячеек,
  прогоняет их одним батчем и раскладывает координаты по трём группам.

Данные о предметах берутся из `model/class_mapping.json`: метка класса →
название, категория и короткое имя, по которому находится иконка.

## Особенности реализации

Несколько мест сделаны неочевидно — там, где очевидное решение не работает.

**Порядок импорта в `app.py`.** `onnxruntime` обязан загрузиться раньше PyQt5:
PyQt5 добавляет в путь поиска DLL свою копию msvc-рантайма, и onnxruntime,
загруженный после него, падает на инициализации.

**Единый масштаб DPI.** Переменная `QT_QPA_PLATFORM=windows:dpiawareness=1`
выставляется до загрузки Qt. Иначе при переносе окна между мониторами с разным
масштабом Qt5 пересчитывает геометрию и ломает раскладку: фиксированные размеры
умножаются на коэффициент, окно растёт, элементы разъезжаются.

**Снимок экрана мимо Qt.** Из-за режима выше Qt отдаёт виртуализированные
размеры для неосновных мониторов. `system/screen_capture.py` на время снимка
переключает DPI-контекст потока и работает напрямую с GDI, получая настоящие
пиксели.

**Окно поверх игры невидимо для скриншота.** `SetWindowDisplayAffinity` с флагом
`WDA_EXCLUDEFROMCAPTURE` — иначе следующий снимок сфотографировал бы
нарисованные нами квадраты и модель попыталась бы их распознать.

**Ленивая загрузка иконок.** 1210 картинок 512×512 не помещаются в память
целиком, поэтому в `QPixmap` превращаются только те, что попали в видимую
область. Загрузка идёт порциями по 40 мс с возвратом управления интерфейсу —
иначе окно замирает и индикатор загрузки не анимируется.

**Фильтр категорий прячет контейнер.** Пока родитель скрыт, Qt копит изменения
видимости дочерних виджетов и разбирает их одним проходом. Без этого
переключение на «All» занимало 2.5 секунды вместо 30 мс.

**Горячие клавиши через `RegisterHotKey`.** Обычный фильтр событий Qt видит
клавиши только когда окно активно, а фокус у игры. Бинд запоминает физический
код клавиши, а не символ, поэтому одна и та же клавиша работает и как `[`, и
как `х` на другой раскладке.
